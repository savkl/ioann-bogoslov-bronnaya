# Храм Иоанна Богослова на Бронной

Статический сайт: расписание богослужений, история, духовенство, таинства и приходская жизнь.

HTML, CSS и JavaScript. Для просмотра достаточно статического HTTP-сервера. Публикация через GitHub Pages из ветки `main`, корневая папка.

Поддерживаются адаптивная вёрстка и настройка уменьшения движения.
